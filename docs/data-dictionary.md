# Data Dictionary

| Column | Type | Description |
|---|---|---|
| job_id | String | Unique job identifier |
| job_title | String | Job title |
| company | String | Hiring company |
| location | String | Job location |
| salary_min | Numeric | Minimum salary |
| salary_max | Numeric | Maximum salary |
| experience | String | Required experience |
| description | Text | Full job description |
| employment_type | String | Full-time, part-time, etc. |
| remote | Boolean | Whether the job is remote |
| posted_date | Date | Job posting date |
